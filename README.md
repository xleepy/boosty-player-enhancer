# Boosty Player Enhancer

Расширение Chrome для просмотра видео в постах Boosty. Добавляет автопроигрывание следующего ролика и режим **«На всё окно»** со штатными элементами управления VK Video. Текущая версия — **1.2.1**. В списке расширений Chrome отображается как **Boosty Autoplay**.

## Установка

Сборка не нужна: расширение загружается прямо из папки с исходниками.

1. Нажмите **Code → Download ZIP** на [странице репозитория](https://github.com/xleepy/boosty-player-enhancer) и распакуйте архив в постоянную папку. Либо клонируйте репозиторий:

   ```sh
   git clone https://github.com/xleepy/boosty-player-enhancer.git
   ```

2. Откройте `chrome://extensions` в Chrome.
3. Включите **Режим разработчика** и нажмите **Загрузить распакованное расширение**.
4. Выберите папку **`extension`** внутри скачанного репозитория. В ней должен находиться `manifest.json`.
5. Обновите уже открытую вкладку Boosty.

Не удаляйте и не перемещайте подключённую папку: Chrome загружает расширение из неё.

## Использование

Откройте страницу конкретного поста Boosty с несколькими видео. В плеере появятся две кнопки в стиле штатной панели. До первого запуска они находятся в правом верхнем углу.

| Кнопка | Действие |
| --- | --- |
| Переключатель с треугольником ▶ | Включает или выключает **автопроигрывание**. Подсказка показывает текущее состояние. |
| Прямоугольная иконка | Включает **«На всё окно»**. При повторном нажатии возвращает плеер в пост. |

### Автопроигрывание

Включите переключатель и запустите первое видео. После его окончания расширение запустит следующий ролик в порядке расположения в этом же посте. Следующий ролик начинается с начала и получает ту же громкость, состояние отключения звука и скорость воспроизведения. После последнего видео очередь останавливается, без повтора по кругу.

Настройка сохраняется между посещениями Boosty. Её также можно изменить через иконку расширения в панели Chrome.

### На всё окно

Нажмите прямоугольную кнопку: плеер займёт всю область вкладки, а вкладки и адресная строка Chrome останутся видимыми. Пауза, перемотка, громкость, настройки и остальные штатные элементы управления сохраняются. При автопереходе следующий ролик показывается в той же области.

Для возврата к текущему ролику в посте нажмите **«Вернуть в пост»** или **Esc**. Если открыто меню плеера, первое нажатие Esc закрывает меню.

Режим окна работает независимо от автопроигрывания: можно развернуть один ролик, не включая очередь. Выключение автопроигрывания также не сворачивает плеер.

Обычный полный экран остаётся доступен через штатную кнопку плеера, **F** и двойной щелчок. Если открыть его из режима окна, при автопереходе расширение выйдет из полного экрана и покажет следующий ролик в режиме **«На всё окно»**. В обычном полном экране Esc сначала выходит из него.

## Обновление

Если репозиторий клонирован, выполните `git pull` в его папке. Если установлен из ZIP, скачайте новую версию и замените файлы в той же подключённой папке, сохранив путь к `extension`.

Затем нажмите кнопку обновления карточки **Boosty Autoplay** в `chrome://extensions` и обновите вкладку Boosty. Изменения исходников сами по себе не обновляют уже загруженную страницу.

## Если что-то не работает

- **Нет новых кнопок:** проверьте, что расширение включено, выбран каталог `extension`, а вкладка Boosty обновлена. Нужна страница отдельного поста, а не лента автора.
- **Браузер блокирует запуск следующего видео:** нажмите **«Продолжить»** в появившемся уведомлении.
- **Видео не загружается или недоступно:** проверьте, открывается ли оно штатным плеером и есть ли доступ по подписке. Расширение не обходит ограничения Boosty.
- **После обновления Boosty кнопки или переходы сломались:** разметка сайта могла измениться. [Создайте issue](https://github.com/xleepy/boosty-player-enhancer/issues) с описанием проблемы и версией расширения.

## Совместимость и данные

Работает на страницах `https://boosty.to/<автор>/posts/<ID>` с плеером VK Video. Очередь ограничена текущим постом; соседние посты и лента в неё не включаются.

Расширение использует Manifest V3 и запускается только на `https://boosty.to/*`. Разрешение `storage` сохраняет переключатель автопроигрывания. Аналитики, серверной части и дополнительных сетевых запросов нет. Видео загружает сам Boosty в вашей обычной сессии.

## Разработка

Нужен **Node.js 22 (от 22.12.0) или Node.js 24 и новее**. Зависимости нужны только для тестов, не для установки расширения.

```sh
npm ci
npm run check
npm test
```

```text
extension/
  vk-player.js     разметка VK, кнопки и единый процесс запуска видео
  autoplay.js      очередь, отмена переходов и повторные попытки
  window-view.js   режим окна, геометрия, фокус и Esc
  content.js       жизненный цикл страницы и синхронизация настроек
  content.css      размещение плеера и уведомлений
  popup.*          переключатель в панели Chrome
tests/
  helpers/         общая модель страницы и плеера
  *.test.cjs       сквозные сценарии и регрессии воспроизведения
package.json       команды и зависимости для тестов
package-lock.json  зафиксированные версии зависимостей
```

Модули загружаются в порядке, указанном в `manifest.json`; сборщик не нужен. Каждый модуль хранит своё состояние. Наружу передаются управляющие интерфейсы плееров, а внутренние DOM-ссылки, наблюдатели и ожидающие операции остаются внутри своих компонентов.

48 автоматических сценариев проверяют очередь, отмену переходов, режим окна, взаимодействие со штатными элементами управления, ленивую загрузку, снятие стартового превью и коллизии имени реестра с HTML-элементами. Они используют JSDOM — модель структуры страницы; это не заменяет проверку настоящего браузерного воспроизведения, геометрии и изменений разметки Boosty.

Версия 1.2.0 дополнительно проверена через интерфейс Chrome на настоящем посте Boosty: автоматический переход с первого ролика на второй в обычном режиме и «На всё окно», воспроизведение кадров без зависшего превью и возврат в пост по Esc.

### Изменения в 1.2.1

- Реестр модулей создаётся как собственное свойство `globalThis` с объектом без прототипа. HTML-элементы с именем `BoostyEnhancer` больше не подменяют реестр при запуске.
- В манифесте явно указан `ISOLATED`: JavaScript расширения выполняется отдельно от кода страницы.
- Добавлены три регрессии для совпадающего `id`, повторяющихся `id` и именованного `iframe`. Создание защищённого реестра также проверено в изолированном контексте Chrome.

### Изменения в 1.2.0

- Первый запуск и «Продолжить» используют один процесс подготовки видео: настройки применяются до запуска подготовленного медиапотока, начало ролика устанавливается после загрузки метаданных.
- Замена видео во время ожидания не считается успешным запуском старого элемента: новый медиапоток подготавливается заново.
- Поздно появившаяся штатная кнопка Play активируется после появления.
- Ручной выбор другого ролика, отключение очереди и переход на другую страницу отменяют прежнюю попытку и её кнопку «Продолжить».
- Разметка плеера, автопроигрывание, режим окна и запуск расширения разделены на модули с собственным состоянием.
